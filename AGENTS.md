# Mermaid Editor

`npm ci && npm run build` baut die Web-Oberfläche. `npm run dev -- --no-open --stay` startet die Vorschau auf Loopback. Für die Mac-App verwende den GitHub-Actions-Workflow «macOS-App bauen» oder `npm run app` auf macOS.

Für Android verwende `npm run android` mit JDK 17 und Android SDK 34 (Build Tools 34.0.0).
